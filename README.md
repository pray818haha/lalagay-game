# 多人在线网页游戏大厅

Node.js + WebSocket 实现的多人实时网页游戏大厅，无需注册登录，打开网页即分配玩家编号。

**包含 7 个游戏**：三国杀（基础）、UNO、大富翁（基础）、麻将（吃碰杠胡）、文字麻将（纯文字渲染）、斗地主（3 人）、掼蛋（4 人两副牌）。

> 仅供私人娱乐，请勿上架任何应用商店/小程序平台。

---

## 一、本地运行（开发/测试）

### 环境要求
- Node.js >= 14（推荐 18+），自带 npm

### 步骤
```bash
# 1. 进入项目目录
cd 项目目录

# 2. 安装依赖（只有 ws 一个依赖，免费开源）
npm install

# 3. 启动
npm start
```

启动后控制台显示 `http://0.0.0.0:3000`。
- 本机访问：http://localhost:3000
- 同一 WiFi 的手机/其他电脑访问：`http://<你的电脑局域网IP>:3000`（如 `http://192.168.1.5:3000`，Windows 用 `ipconfig` 查看 IPv4 地址；如无法访问，检查防火墙是否放行 3000 端口）

改端口：`set PORT=8080 && npm start`（Windows）或 `PORT=8080 npm start`（Linux/Mac）。

## 二、在线联机部署（公网访问）

游戏通信走 WebSocket，部署到任何一台有公网 IP 的服务器即可让朋友通过浏览器直接访问。

### 方案 A：自己的云服务器（推荐，腾讯云/阿里云/华为云轻量服务器均可）

1. 购买任意最便宜的 Linux 云服务器（1核1G 足够 4 人游玩）。
2. 安装 Node.js：
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo bash -
   sudo apt install -y nodejs
   ```
3. 上传项目代码（`git clone` 或 `scp -r ./项目目录 user@服务器IP:/opt/game-lobby`）。
4. 启动并常驻：
   ```bash
   cd /opt/game-lobby
   npm install
   sudo npm install -g pm2
   pm2 start server.js --name game-lobby
   pm2 save && pm2 startup   # 开机自启
   ```
5. **放行端口**：在云服务商控制台的「安全组/防火墙」中放行 TCP 3000 端口（服务器系统防火墙如有也放行）。
6. 朋友访问 `http://<服务器公网IP>:3000` 即可联机。

### 方案 B：免费 PaaS 平台（无需买服务器）

以下平台都有免费额度，支持 Node.js + WebSocket：

- **Render**（render.com）：New → Web Service → 连接 GitHub 仓库 → Build 命令 `npm install`，Start 命令 `node server.js`。免费实例会休眠，首次访问稍慢。
- **Railway**（railway.app）：New Project → Deploy from Repo，自动识别 Node.js。
- **Glitch**（glitch.com）：直接导入项目在线运行。

平台会自动分配 `https://xxx.onrender.com` 之类的域名，把链接发给朋友即可（前端会自动使用 `wss://` 安全连接）。

### 方案 C：内网穿透（自己电脑做服务器）

如果只是临时和朋友玩几局，不想买服务器：
- 安装 [cpolar](https://www.cpolar.com/) / natapp / frp 等内网穿透工具（均有免费档）。
- 本地 `npm start` 后，执行 `cpolar http 3000`，把生成的公网地址发给朋友。

## 三、玩法说明

1. 打开网页自动分配玩家编号（玩家1、玩家2…）。
2. 任选游戏点「创建房间」，把**房间号**告诉朋友，他们在大厅房间列表点「加入」。
3. 人满后房主/任意玩家点「开始游戏」（斗地主需 3 人，其余需 4 人）。
4. 房间内房主可在开局前「切换游戏」。
5. 一局结束后点「再来一局」重开。

### 🤖 单人测试：电脑玩家替补

不用等真人凑齐，一个人也能测试全部游戏：

- 创建房间后点「**🤖 一键填满电脑**」，空位立即由电脑补满，直接开始；
- 也可在每个空位上单独点「＋ 添加电脑」；
- 电脑会自动完成出牌/摸牌/吃碰杠胡/掷骰子等全部操作，你只需操作自己的回合；
- 添加电脑仅限开局前、仅房主可操作；切换游戏时多余电脑会自动移除。

电脑思考间隔默认 0.65～1.25 秒（便于观察）。想加速可在启动时设置环境变量，例如 `BOT_DELAY=100 npm start`（Windows：`set BOT_DELAY=100 && npm start`）。

## 四、技术说明

- 后端：Node.js 原生 `http` 提供静态文件 + `ws` 库处理 WebSocket（唯一依赖，MIT 开源）。
- 前端：原生 HTML/CSS/JS，无框架，无图片资源（全部用文字/emoji/CSS 渲染牌面），同时适配电脑与手机浏览器。
- 状态同步：服务端权威状态机，每个操作后向房间内各玩家推送**各自视角**的裁剪状态（看不到别人的手牌）。
- 断线处理：玩家断线后保留座位，未开局直接移除，房间空了自动销毁。刷新页面会分配新编号（重连回座位为后续迭代项）。

## 六、已知简化与后续可迭代项

- 三国杀：仅 杀/闪/桃 三种牌、无武将技/装备/距离/身份局，濒死自动用自己的桃（未实现求桃询问）；桃使用后移出牌堆（保证对局必有胜负）。
- 大富翁：24 格小地图，含所得税/印花税格与机会卡；无盖房/抵押/拍卖；4 人局剩 2 人时按现金直接结算（避免长局僵持）。
- 麻将：胡牌只判断基本型（无番种计分），无补花、无抢杠胡、无杠上开花计分。
- 斗地主：随机地主（未实现叫分/抢地主），未实现春天/炸弹翻倍计分。
- 掼蛋：固定级牌 2，未实现升级流转/逢人配（红桃级牌百搭）/进贡还贡/同花顺炸弹。
- 电脑 AI 以"能走完流程"为目标：会出杀响应闪、跟牌、吃碰杠胡（带概率）、买地等，但不算牌、不拆复杂牌型，适合测试与休闲。
- 通用：无观战、无聊天、无断线重连回座位、无对局回放。

基础流程（建房→加入→开局→回合/出牌→胜负判定→再来一局）均已跑通，以上增强点可在各 `games/*.js` 模块内独立迭代，互不影响。
